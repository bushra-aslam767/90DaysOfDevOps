LINUX ARCHITECTURE:
 LINUX ARCHITECTURE is base on the 4 layers (ASK)
 1- A (APPLICATION/USER) : USER USES THE COMMANDS / PROGRAM
 2- S (SHELL) : INTERACTIVE WAY TO TALK TO KERNEL
 3- K (KERNEL) :  IT MANAGES THE CPU , MEMORY(RAM)
 4- HARDWARE  :   MONITOR , SPEAKER , PRINTR 
 
CORE COMPONENET OF LINUX:
KERNEL:
    KERNEL is the core part of the linux operating sysytem.
IMPORTANCE OF KERNEL:
1-  It manages the CPU.
2-  IT manages the memory(RAM)
3-  IT controls the devices like (keybooard , mouse)
4-  IT handles the files and storage

USER SPACE:
    USER SPACE is the area of operating system where normal applies run is happen.

 SYSTEMD:
    SYSTEMD is the system & service manager of linux.
    SYSTEMD starts linux & manges the services running in the  background.

  Process = A program that is currently running.
  
  Process Creation:
         A new process can be created when:

1- A user runs a command/program.
2- A process creates another process using fork().
3- The new process can run a different program using exec().

The Kernel manages processes by:

1- Giving each process a PID (Process ID)
2- Giving CPU time to processes
3- Managing memory
4- Starting and stopping processes
5- Scheduling which process runs next
