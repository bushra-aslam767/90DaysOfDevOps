LINUX COMMANDS CHEAT SHEET:
A quick reference for process management, file system, and networking troubleshooting.

1. Process Management:

ps : Shows running processes.
top : Displays processes and live CPU/memory usage.
htop : Shows processes in an interactive view.
pgrep : Finds a process by name.
kill PID : Stops a process using its process ID.
pkill name : Stops processes by name.
jobs : Lists background jobs in the current terminal.
bg : Resumes a stopped job in the background.
fg : Brings a background job to the foreground.

2. File System:

pwd  :  Shows the current directory path.
cd folder :  Moves into a directory.
ls : displays a list of files and folders.
ls -l :  display a deatiled list of file and folder.
ls -a :  display a hidden files & folder.
ls -t : sorting file and folder.
mkdir folder : Creates a new directory.
touch file.txt : Creates an empty file.
cp file : Copies a file to a destination.
mv file : Moves or renames a file.
rm file : Deletes a file.
rmdir folder : Removes an empty directory.
rm -r folder : Removes a directory and its contents.
cate file.txt : Displays file contents.

Networking Troubleshooting:

ip addr : Displays network interfaces and IP addresses.
ping google.com : Checks connectivity to a host.
ip route : Shows the routing table.
dig google.com : Checks DNS records and resolution.
